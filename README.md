Fitra is an AI-powered Android application designed to create a safer digital environment for children by filtering inappropriate YouTube content. The application leverages Artificial Intelligence (AI), Natural Language Processing (NLP), and Deep Learning to analyze video content and recommend child-safe alternatives, helping parents monitor and protect their children's digital experience while respecting cultural and family values.

The project integrates mobile application development, artificial intelligence, cloud technologies, and software engineering to deliver an intelligent parental control solution.

# 🏗️ System Architecture

The application follows a three-layer architecture to separate user interaction, backend processing, and AI-based content analysis.

- Flutter Mobile Application
- Child Interface
- Parent Dashboard

## Backend Layer

- Flask REST API

- Authentication & Data Management

## AI Layer

- YouTube Video Analysis
- Speech-to-Text Processing
- Natural Language Processing
- Deep Learning Classification
- Content Recommendation Engine

---

# 🤖 AI Pipeline

The AI filtering process consists of multiple stages:

1. Audio Extraction using **yt-dlp**
2. Speech-to-Text conversion using **Whisper AI**
3. Language Detection and Translation
4. Text Cleaning and Preprocessing
5. FastText Embedding Generation
6. Deep Learning Classification using **CNN + LSTM**
7. Reinforcement Learning Optimization

---

# 📈 Model Performance

The AI model was trained and evaluated using a custom dataset containing more than **14,000 manually labeled YouTube videos**.

The integration of Reinforcement Learning with supervised learning improved the model by increasing:

- Recall
- CHAP Score
- Detection accuracy
- Classification reliability
- Reduction of false positive predictions
